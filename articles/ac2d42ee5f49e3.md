## WSL環境を作成
```powershell
mkdir D:\WSL\pgsql_env
wsl --import pgsql_env D:\WSL\pgsql_env D:\WSL\ubuntu-24.04-server-cloudimg-amd64-root.tar.xz --version 2
```

### 作成したWSLを起動
```powershell
wsl -d work_env
```
これでrootユーザーでWSLに接続する

### pgsqlユーザーを作成
```bash
adduser pgsql
```
pgsqlユーザーをsudoグループに追加
```bash
usermod -aG sudo pgsql
```

### WSL起動時のデフォルトユーザーを設定
/etc/wsl.confに以下を設定
```
[user]
default=pgsql
```
exitでshellを終了

### WSLを再起動
```powershell
wsl --terminate pgsql_env
wsl -d pgsql_env
```
これでpgsqlユーザーで接続される

### 必要なパッケージをインストール
```bash
sudo apt update
sudo apt install \
  build-essential \
  flex \
  bison \
  gdb \
  libreadline-dev \
  zlib1g-dev \
  libssl-dev \
  gettext \
  pkg-config \
  libicu-dev
```

### ソースコードを取得
公式(https://git.postgresql.org/git/postgresql.git)はタイムアウトする場合がある
Githubミラーから取得するほうが安定している
```bash
cd ~
mkdir src
cd src
git clone https://github.com/postgres/postgres.git
```

Ver.18.1をチェックアウト
```bash
cd ~/src/postgres
git checkout REL_18_1
```

### ビルド

インストール先などは環境変数で設定しておくとよい
~/.bashrcに以下を記述して、source ~/.bashrcで反映
```bash
export PGHOME=$HOME/pgsql
export PGDATA=$PGHOME/data
export PGLIB=$PGHOME/lib
export PATH=$PATH:$PGHOME/bin
export PGSETUP_INITDB_OPTIONS="--encoding=UTF-8 --no-locale"
```

ビルド実行
``` bash
mkdir -p ~/src/build/build_18_1_g
cd ~/src/build/build_18_1_g
export CFLAGS=''
../../postgres/configure --prefix=$HOME/pgsql --with-openssl --enable-nls=UTF_JP --enable-debug
make -j 4
make check
make install
```

DBを作成
``` bash
initdb --encoding=UTF-8 --no-locale
pg_ctl -D $PGDATA -l logfile start
createdb
```

### デバッガでアタッチしてみる
psqlで接続
``` bash
psql
```

別のpowershellを起動して、wslに接続
```powershell
wsl -d pgsql_env
```

バックエンドプロセスを特定
```bash
ps -ef | grep postgres
```

以下のような行のPIDを取得 (以下の例ではPID=21191)
```
pgsql    21191 21165  0 00:02 ?        00:00:00 postgres: pgsql pgsql [local] idle
```

デバッガでアタッチしてみる
``` bash
cd $PGHOME/bin
gdb postgres 21191
```

以下のメッセージが出る場合の対応
```
Attaching to program: /home/pgsql/pgsql/bin/postgres, process 21191
Could not attach to process.  If your uid matches the uid of the target
process, check the setting of /proc/sys/kernel/yama/ptrace_scope, or try
again as the root user.  For more details, see /etc/sysctl.d/10-ptrace.conf
ptrace: Operation not permitted.
```

ptrace_scopeを0に設定する
```bash
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope
```

OS再起動時にもptrace_scopeを0にしたい場合、/etc/sysctl.d/10-ptrace.confを編集
```bash
sudo vi /etc/sysctl.d/10-ptrace.conf
```
/10-ptrace.confに以下を設定して保存
```
kernel.yama.ptrace_scope = 0
```

これで再度アタッチしてみる
``` bash
cd $PGHOME/bin
gdb postgres 21191
```

以下が表示されたらyを入力
```
This GDB supports auto-downloading debuginfo from the following URLs:
  <https://debuginfod.ubuntu.com>
Enable debuginfod for this session? (y or [n]) y
```
