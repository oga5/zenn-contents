# PostgreSQLの起動プロセス
PostgreSQLをpg_ctl startで起動したときの処理を見る

gdb pg_ctlでデバッガで観察する

breakpointをセットして実行
```
break main
break do_start
break start_postmaster
run start --timeout 10000 > /dev/null
```

mainで停止したらcontinue
```
Breakpoint 1, main (argc=4, argv=0x7fffffffe098) at ../postgres/src/bin/pg_ctl/pg_ctl.c:2203
warning: 2203   ../postgres/src/bin/pg_ctl/pg_ctl.c: No such file or directory
```

do_startで停止したら、btでスタックトレースを見てからcontinue
```

932     in ../postgres/src/bin/pg_ctl/pg_ctl.c
```

start_postmasterで停止したら、set follow-fork-mode childでfork後に子プロセスをデバッグできるようにする
nextで進めて、fork直後のpm_pidをprint
pm_pid = 0になっていたら子プロセスにいる

nextで進めていく
setsidで親のpg_ctlプロセスと切り離して、pg_ctl終了時に子プロセスは終了しないようにしている
次にcmd変数にコマンドラインを作成して、execlで実行している
/bin/shを起動しているのは標準入力を/dev/nullにしたり、ログファイル名の指定がある場合のファイル名を指定するのが簡単なため
/bin/shでexec postgresしているので、shがすぐにpostgresをexecする動作になる
(pg_ctlからshをexecして、shがpostgresをexec)
```
(gdb) n
462             if (pm_pid > 0)
(gdb)
476             if (setsid() < 0)
(gdb)
489             if (log_file != NULL)
(gdb)
494                     cmd = psprintf("exec \"%s\" %s%s < \"%s\" 2>&1",
(gdb)
497             (void) execl("/bin/sh", "/bin/sh", "-c", cmd, (char *) NULL);
(gdb) print cmd
$2 = 0x555555571ef0 "exec \"/home/pgsql/pgsql/bin/postgres\"  < \"/dev/null\" 2>&1"
```
