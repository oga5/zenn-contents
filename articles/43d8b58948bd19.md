WSLチートシート

インストール済みのディストリビューションリスト

```powershell
wsl --list -v
```

インストール可能なディストリビューションリスト

```powershell
wsl --list --online
```

起動してシェルに入る

```powershell
wsl -d <ディストリ名>
```

ディストリビューションをインストール

```powershell
wsl --install <ディストリ名>
```

ディストリ名にUbuntuを指定した場合は、最新のLTSが入る (2025年6月時点では24.04LTS)

ディストリビューションを削除

```powershell
wsl --unregister <ディストリ名>
```

ディストリビューションを停止

```powershell
wsl --terminate <ディストリ名>
```

全部停止する場合はshutdown

```powershell
wsl --shutdown
```

wsl —installではMicrosoft Store 経由で Cドライブの既定の場所（通常は %LOCALAPPDATA%\Packages\）にインストールされる
Cドライブ以外の場所に移動したい場合はexport/importする

export/importを使うことで、環境を複数作成することもできる

既存の環境をDドライブに移動 (D:\WSL\ubuntu以下にハードディスクイメージを保存)

```powershell
mkdir D:\wsl
mkdir D:\wsl\ubuntu
wsl --export <ディストリ名> D:\wsl\<任意の名前>.tar
wsl --unregister <ディストリ名>
wsl --import <新しいディストリ名> D:\wsl\ubuntu D:\wsl\ubuntu_backup.tar
```

ベースイメージをクリーンインストールしたい場合

https://cloud-images.ubuntu.com/releases/noble/　から

ubuntu-24.04-server-cloudimg-amd64-root.tar.xzをダウンロード

```powershell
mkdir D:\WSL\work_env
wsl --import work_env D:\WSL\work_env D:\WSL\ubuntu-24.04-server-cloudimg-amd64-root.tar.xz --version 2
```

インストールしたら起動して、デフォルトユーザーを作成

```powershell
wsl -d work_env
```

以下はlinuxのrootで作業

ユーザーを作成して、起動時にこのユーザー名で接続できるようにする

```powershell
adduser username
usermod -aG sudo username
```

/etc/wsl.confに以下を設定して、ディストリビューションを再起動

```powershell
[user]
default=username
```

デフォルトで起動するディストリビューションを設定

```powershell
wsl --set-default <ディストリ名>
```
