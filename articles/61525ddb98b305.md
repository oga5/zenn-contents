# Windowsでmysqlをビルド

## 事前準備
### Visual Studio 2026をインストール
C++によるデスクトップ開発を選択し、以下のオプションを入れる
- x64/x86用MSVCビルドツール
- Windows用C++ CMakeツール
- vcpkgパッケージマネージャー

## Developer Command Prompt for VSで実行する
作業ディレクトリ: d:\data\mysql

## 必要なライブラリをビルド
git clone https://github.com/microsoft/vcpkg.git
.\vcpkg\bootstrap-vcpkg.bat
.\vcpkg\vcpkg install openssl[tools]:x64-windows --recurse
.\vcpkg\vcpkg install libevent:x64-windows
.\vcpkg\vcpkg install zlib:x64-windows lz4:x64-windows zstd:x64-windows

## bisonの取得
以下をダウンロードして解凍
https://github.com/lexxmark/winflexbison/releases/download/v2.5.25/win_flex_bison-2.5.25.zip

D:\data\mysql\win_flex_bison-2.5.25

## MySQLのダウンロード
https://dev.mysql.com/downloads/mysql/8.4.html
Source Codeを選択
Windows用zipをダウンロードして展開する

D:\data\mysql\mysql-8.4.8

## MySQLのソースディレクトリにて
cd mysql-8.4.8
mkdir build
cd build

set CL=/utf-8

cmake .. -G "Visual Studio 18 2026" -A x64 ^
  -DCMAKE_TOOLCHAIN_FILE="D:/data/mysql/vcpkg/scripts/buildsystems/vcpkg.cmake" ^
  -DWITH_SSL=system ^
  -DWITH_LIBEVENT=system ^
  -DWITH_PROTOBUF=bundled ^
  -DWITH_ABSL=bundled ^
  -DWITH_ICU=bundled ^
  -DWITH_LZ4=system ^
  -DWITH_ZSTD=system ^
  -DWITH_ZLIB=system ^
  -DOPENSSL_ROOT_DIR="D:/data/mysql/vcpkg/installed/x64-windows" ^
  -DOPENSSL_EXECUTABLE="D:/data/mysql/vcpkg/installed/x64-windows/tools/openssl/openssl.exe" ^
  -DBISON_EXECUTABLE="D:/data/mysql/win_flex_bison-2.5.25/win_bison.exe" 

cmake --build . --config RelWithDebInfo

ビルド中のエラー
D:\data\mysql\mysql-8.4.8\router\src\destination_status\src\unreachable_destinations_quarantine.h(262,9): error C2664:

unreachable_destinations_quarantine.hの262行目付近を以下のようにする
//    std::error_code last_ec_{
//        make_error_code(std::errc::no_such_file_or_directory)};
    std::error_code last_ec_{
        make_error_code(static_cast<IoComponentErrc>(std::errc::no_such_file_or_directory))};

cmake --install . --prefix "D:\data\mysql\dist" --config RelWithDebInfo

## vcpkgでビルドしたdllをmysqlのbinディレクトリにコピー
copy "D:\data\mysql\vcpkg\installed\x64-windows\bin\*.dll" "D:\data\mysql\dist\bin\"

## データベースの初期化
cd D:\data\mysql\dist\bin
mysqld --initialize --user=mysql --datadir=D:\data\mysql\dist\data

D:\data\mysql\dist\dataに.errファイルができる
ここに初期パスワードが出力されているので確認

### MySQLサーバを起動
mysqld --datadir=D:\data\mysql\dist\data --console

### 別ウィンドウで接続
mysql -u root -p
(初期パスワードを入力)

### MySQL rootのパスワードを変更
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY '新しいパスワード';
quit

### MySQLユーザーの作成、DB作成
mysql -u root -p
CREATE USER 'winuser'@'%' IDENTIFIED BY 'winpass';
GRANT ALL PRIVILEGES ON *.* TO 'winuser'@'%';
FLUSH PRIVILEGES;

CREATE DATABASE mydb CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;

GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, DROP, EXECUTE ON mydb.* TO 'winuser'@'%';
