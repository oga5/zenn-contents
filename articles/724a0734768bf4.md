WSLで起動したPostgreSQLにWindowsホストから接続する設定

postgresql.confでlisten_addressを設定
```
listen_addresses = '*'
```

pg_hba.confに以下を追加
```
host    all             all             0.0.0.0/0               md5
```

WSLのIPアドレスを確認
```
ip addr show eth0
```

postgresを起動
```
pg_ctl start
```

Windowsから接続確認
